# สวัสดีครับ 👋 ผม Zee Nontakorn

**Web Developer** ประสบการณ์ประมาณ 3 ปี และฝึกงานด้านพัฒนาเว็บตั้งแต่ พ.ศ. 2565 (2022) ทำระบบเว็บที่ใช้งานจริงให้ลูกค้าทั้งภาคเอกชนและหน่วยงานรัฐ ตั้งแต่เก็บ requirement ไปจนถึง deploy และดูแลหลังส่งมอบ

- 🖥️ **ระบบที่ใช้งานจริง:** ระบบสหกรณ์โรงเรียน (POS), ระบบคลังอะไหล่อู่แต่งรถ, ระบบไกล่เกลี่ยออนไลน์, ระบบแจ้งซ่อม, ระบบจองสนามบาส (ลูกค้าทดลองใช้)
- 🤖 **ทำงานกับ AI ช่วยเขียนโค้ด:** ผมเป็นคนกำหนดโจทย์ ข้อจำกัด และตรวจรับ เช่น การย้าย backend ของ FixDesk จาก Node.js เป็น Laravel โดยคง API เดิมทุกจุด (ระบุไว้ตรงๆ ใน case study)
- 👥 **พี่เลี้ยงนักศึกษาฝึกงาน:** แบ่งงาน รีวิวโค้ด วางกระบวนการรวม branch ในทีมที่มีผู้พัฒนาหลายคน
- 🌐 **ดูแลระบบเอง:** deploy ด้วย Docker Compose, nginx reverse proxy, HTTPS และแก้ปัญหาตอนระบบล่มบน VPS

## เทคโนโลยี

| ด้าน | ที่ใช้ |
|---|---|
| Frontend | Vue 2 / Vue 3, Vuex, Pinia, Vuetify, Tailwind CSS, TypeScript, Leaflet |
| Backend | Laravel, Node.js (Express), CodeIgniter 3 |
| ฐานข้อมูล | MySQL, MongoDB, PostgreSQL (Prisma) |
| API และการเชื่อมต่อ | REST, JWT, LINE Messaging API, Webex API, SMS |
| DevOps | Docker Compose, nginx, systemd, VPS และ shared hosting |
| เครื่องมือ | Git (feature branch, PR, cherry-pick, revert, reflog), Composer, Vite |
